# Quiz de Fútbol: Adivina el Escudo (Edición Torneo de Fuerza)

Una aplicación web interactiva que fusiona la estética y actitud de Dragon Ball con tu conocimiento futbolístico. El "Entrenador Vegeta" seleccionará 10 escudos aleatorios de clubes europeos, y deberás adivinar a qué equipo pertenecen.

## Características
- **Base de datos:** 30 escudos de equipos reales importados desde un CDN público (`football-data.org`).
- **Modo "Sin Nombre":** Se aplica un ligero filtro visual (desenfoque) mediante CSS a los escudos para dificultar la lectura de los nombres impresos en ellos. ¡Al responder, el escudo se revela con claridad!
- **Temática Visual:** Colores naranja y azul (estilo traje de Goku), con botones dinámicos y sombras marcadas.
- **Sistema de insultos:** Feedback final basado en tu puntaje con el tono arrogante de Vegeta.

## Cómo ejecutar el proyecto
1. Crea una carpeta llamada `quiz-escudos`.
2. Dentro, crea los archivos `index.html`, `style.css` y `script.js`.
3. Pega el código de cada bloque en su archivo correspondiente.
4. Abre `index.html` en tu navegador. No necesitas descargar imágenes ni configurar servidores.
